# CM-1001-spike-into-embedcodes-in-textareas

A proof-of-concept demo for detecting cursor position and mouse clicks in a textarea, designed for embed code insertion functionality.

## 🚀 GitHub Pages Deployment

This project is configured to automatically deploy to GitHub Pages using GitHub Actions.

### Setup Instructions

1. **Enable GitHub Pages in your repository:**
   - Go to your repository on GitHub
   - Navigate to **Settings** → **Pages**
   - Under **Source**, select **GitHub Actions**

2. **Push your changes:**
   ```bash
   git add .github/workflows/deploy.yml
   git commit -m "Add GitHub Pages deployment workflow"
   git push origin main
   ```

3. **View your deployment:**
   - The workflow will automatically run on push to the `main` branch
   - Check the **Actions** tab to monitor the build and deployment
   - Once complete, your demo will be available at: 
     https://neontribe.github.io/CM-1001-spike-into-embedcodes-in-textareas/
   

### Manual Deployment

You can also trigger a deployment manually from the **Actions** tab by clicking "Run workflow" on the "Build and Deploy to GitHub Pages" workflow.

## 🛠️ Local Development

### Install dependencies
```bash
npm install
```

### Build the project
```bash
npm run build
```

### Development with live reload
```bash
npm run dev
```

This will start a development server at `http://localhost:8080` with live reloading.

### Watch mode only (without server)
```bash
npm run watch
```

## 📝 Project Structure

- `index.html` - Main HTML file with the demo interface
- `src/main.ts` - Main TypeScript entry point
- `src/regex.ts` - Regex utilities for embed code detection
- `dist/` - Compiled JavaScript output (generated by TypeScript compiler)
